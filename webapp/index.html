Privacy notice

Microphone audio is streamed to Cartesia only while a live session is active. The short-lived provider token is requested from the authenticated Aura backend and is never stored in browser storage.

Requirements

HTTPS, microphone permission, configured Cartesia credentials and an OpenAI-compatible LLM key are required. Ink-2 live STT currently supports English, Spanish, French, Hindi and Japanese.
